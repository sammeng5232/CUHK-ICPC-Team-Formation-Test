# CUHK ICPC Team Formation Test

My solutions to the Chinese University of Hong Kong (CUHK) CSE's ICPC team formation (selection) contests — 2017 and 2020–2022.

14 solutions in C++, named `CUHK ICPC TFT_<year>_<problem>.cpp` (the 2017 files carry the contest name `CUHK CSE Contest 2017_<problem>.cpp`).
